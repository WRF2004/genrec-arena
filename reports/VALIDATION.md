# 实际执行报告

2026-10-22；CPU / Python 3.12 / torch 2.14.1+cpu / NumPy 2.3.5。

**仅为人工合成数据验证，不是比赛成绩，不代表真实用户收益。**

96 用户、48 商品、训练时间 <16000，验证 [16000,20000)，测试 >=20000。神经模型各 5 epoch，seed=42，按验证 NDCG@12 选模。

| 模型 | Recall@12 | NDCG@12 | MAP@12 |
|---|---:|---:|---:|
| Popularity | 0.2517 | 0.1767 | 0.0903 |
| ItemKNN | 0.9288 | 0.8767 | 0.8122 |
| Item-ID Transformer | 0.4792 | 0.4796 | 0.3058 |
| SID Transformer (K-Means) | 0.9340 | 0.7336 | 0.5793 |

ItemKNN 的排序质量优于本次 SID 模型，SID 的 Recall 略高。合成数据刻意包含类别周期，不能据此认定某架构更优。相同 epoch 不代表同参数量/同计算预算。
